\begin{abstract}
    The Fiat--Shamir transform is uninstantiable in general: there are protocols for which the resulting scheme is insecure with every concrete hash function (Goldwasser and Kalai, FOCS 2003). The positive results go the other way, instantiating Fiat--Shamir for statistically sound proofs using correlation-intractable hashing. Neither line reaches the signature schemes people deploy. Schnorr and Dilithium come from protocols in which no false statements arise, so soundness is vacuous and correlation intractability has no bad-challenge relation to act on. What these schemes need is unforgeability, which the random-oracle proofs get by extracting from the forger, by programming or rewinding. For these schemes essentially one standard-model result is known: Paillier and Vergnaud (ASIACRYPT 2005) prove key-recovery security for any hash function under the interactive OMDL assumption. We take the question on directly, giving standard-model instantiations under non-interactive assumptions, for Schnorr and for an unstructured scheme of Dilithium's paradigm, including, to our knowledge, the first to achieve existential unforgeability.

    For key recovery, we define tunable lossy functions. Their lossy image bound is a parameter, and our reduction gives an explicit tradeoff among mode indistinguishability, image-enumeration time, and DL security. The proof replaces random-oracle programming by rejection sampling over the enumerated image. Instantiating the construction with Zhandry's strongly efficiently enumerable ELFs gives key-recovery security from ordinary DL in the Schnorr group and exponential DDH in auxiliary groups.

    For unforgeability, we instantiate the hash function with an obfuscated circuit built from puncturable PRFs and a conversion function for the circular discrete-logarithm problem. Polynomially secure CDL, iO, and puncturable PRFs give static-message unforgeability, where the forger declares its signing and forgery messages before seeing the verification key, for a bounded number of signatures fixed at key generation. For a salted variant of Schnorr in which the message enters the hash through a tunable lossy function in injective mode, we prove adaptive EUF-CMA security for messages of any polynomial length. The reduction switches the pre-hash to lossy mode, under its mode indistinguishability, and guesses hash digests from its enumerable image, so the guessing losses are bounded by the image size rather than by the message space. With a quasi-polynomial image bound, quasi-polynomially secure CDL, iO, and puncturable PRFs suffice. The signer samples both its nonce and its salt uniformly and independently.

    Finally, we extend the program to lattice-based Fiat--Shamir with aborts, the paradigm of Lyubashevsky signatures that Dilithium instantiates. For an unstructured scheme of that shape, over a power-of-two modulus with gadget challenges, we prove key-recovery security from search LWE and the same lossy hash family, with no obfuscation; a lattice-based lossy function with the required enumerability, which we pose as an open problem, would make every ingredient lattice-based. We then prove static-message unforgeability from SIS, LWE, iO, and puncturable PRFs, all polynomially secure at a quasi-polynomial modulus. The circular problem here is a SIS analogue of CDL, and for the gadget conversion function it reduces tightly to plain SIS.

    \keywords{Fiat--Shamir signatures \and Schnorr \and Dilithium \and random-oracle instantiation \and lossy functions \and obfuscation}
\end{abstract}
