% [TEMPORARILY DISABLED] \begin{abstract}
% [TEMPORARILY DISABLED]     The random-oracle-based Fiat--Shamir transform is fundamental to constructing practical signature schemes. It is uninstantiable---meaning, its random oracle cannot be securely replaced with a real hash function---in general (Goldwasser and Kalai, FOCS 2003). Here, we ask whether some of the most widely deployed instances of the paradigm can be instantiated. In particular, we study Schnorr signatures and the Lyubashevsky signature paradigm instantiated by Dilithium.
%
% [TEMPORARILY DISABLED]    \quad\quad We begin with adaptive chosen-message key-recovery security for classical Schnorr. The hash applies a tunable lossy-function family generated in its injective mode, followed by an efficient map to the Schnorr challenge space. Only the lossy mode, used in the proof, has a small enumerable image; an exact rejection sampler then simulates signatures without the secret key. The generic reduction exposes a tradeoff: at image bound $r$, mode indistinguishability is needed only against polynomial-time distinguishers, while the discrete-logarithm reduction pays the time required to enumerate the image. We give DDH- and LWE-based TLF instantiations. Zhandry's DDH cascade gives the endpoint with ordinary discrete logarithm in the Schnorr group and exponential DDH in auxiliary groups. The result deliberately places no security condition on the final map and therefore includes degenerate, forgeable choices: key recovery does not imply unforgeability. If a small covering set for the challenges of some message were efficiently computable from the deployed verification key, the same rejection sampler would give a no-query forgery.
%
% [TEMPORARILY DISABLED]    \quad\quad To obtain unforgeability, we use indistinguishability obfuscation and a zero-free conversion function for which the circular discrete-logarithm assumption of Cho, Fuchsbauer, O'Neill, and Sefranek (CRYPTO 2025) is hard. Our first unforgeability result keeps the classical Schnorr signing algorithm, with its randomized nonce, and proves bounded static-message security under polynomially hard assumptions. Its proof hardwires the declared signing points, so its circuit depends on an a priori query bound. The main construction adds a trigger branch that lets the reduction sign without the secret key. A tunable lossy message-digest layer lets the proof guess the digest of each adaptive query from an enumerable image, rather than guessing the message. One trigger gives one signature per message, so our main result is for \emph{Deterministic Schnorr}, whose nonce is a pseudorandom function of the signing key and the message, as in Ed25519; repeated queries then receive the same signature in both the scheme and the proof. We prove fully adaptive EUF-CMA security in the standard model. A fixed quasi-polynomial image bound gives an explicit quantitative tradeoff, while a strongly efficiently enumerable TLF gives an endpoint under ordinary PPT security of the remaining assumptions.
%
% [TEMPORARILY DISABLED]    \quad\quad Finally, we extend the program to lattice-based Fiat--Shamir with aborts, the paradigm of Lyubashevsky signatures that Dilithium instantiates. We prove two static-message unforgeability results, including ordinary static security with no query bound for a deterministic signer. For bounded static security, iO hides the switch to a functionally equivalent circuit with the declared point--value pairs hardwired, puncturable-PRF security replaces the selected masks by uniform values, and LWE replaces the masked inputs by uniform ones; a forgery gives a circular-SIS solution that the bit-decomposition identity converts to SIS. The deterministic theorem adds a PRF-derived trigger to remove the query bound.
%
