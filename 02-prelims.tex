\section{Preliminaries}\label{sec-prelims}

\headingg{Notation.} Strings are identified with vectors over $\bits$, so that $|Z|$ denotes the length of a string $Z$ and $Z_i$ denotes its $i$-th bit. By $x\|y$ we denote the concatenation of strings $x,y$. If $S$ is a finite set, then $|S|$ denotes its size and we let $x \getsr S$ denote picking an element of~$S$ uniformly at random and assigning it to $x$. We use $[n]$ to denote the set $\{1, \dots, n\} \subset \N$. By $\secp \in \N$ we denote the security parameter and by $\usecp$ its unary encoding. A function $\nu \colon \N \to \R$ is negligible if for every polynomial $p$ we have $\nu(\secp) \le 1/p(\secp)$ for all sufficiently large $\secp$.

For a function $f \colon A \to B$, we let $\Image(f) := \{f(a) : a \in A\}$, and we let $\mathsf{Size}_f(b) := |f^{-1}(b)|$ for all $b \in B$.

Algorithms may be randomized unless otherwise indicated. If $\advA$ is an algorithm, we let $y\gets \advA^{\procfont{O}_1,\ldots}(x_1,\ldots ; \omega)$ denote running $\advA$ on inputs $x_1,\ldots$ and coins $\omega$, with oracle access to $\procfont{O}_1,\ldots$, and assigning the output to $y$. Moreover, by $y\getsr \advA^{\procfont{O}_1,\ldots}(x_1,\ldots)$ we denote picking $\omega$ uniformly at random and letting $y\gets \advA^{\procfont{O}_1,\ldots}(x_1,\ldots ; \omega)$. We let $\OutSet{\advA^{\procfont{O}_1,\ldots}(x_1,\ldots)}$ denote the set of all possible outputs of $\advA$ when run on inputs $x_1,\ldots$ and with oracle access to $\procfont{O}_1,\ldots$. Running time is worst-case. We use $\bot$ as a special symbol to denote rejection, and it is assumed not to be in $\bits^*$.

Throughout, we say a computational problem \emph{holds} if every PPT adversary has negligible advantage in the corresponding game.

\heading{Games.} We use the code-based game-playing framework of Bellare and Rogaway~\cite{EC:BelRog06}. By $\Pr[\Gm\Rightarrow y]$ we denote the probability that the execution of game $\Gm$ results in output $y$. In games, integer variables, set variables, boolean variables and string variables are assumed initialized, respectively, to $0$, the empty set $\emptyset$, the boolean $\false$ and $\bot$.

\subsection{Signature Schemes and Schnorr Signatures} \label{sec-schnorr}

\heading{Signature schemes.}
A \emph{signature scheme} with message space $\MsgSp$ is a tuple of algorithms $\SigScheme = (\SigKeys, \SigSign, \SigVf)$ that work as follows. The key-generation algorithm $\SigKeys$ outputs a key pair $(\vkey,\skey)$. (We suppress the security parameter for simplicity.) The signing algorithm $\SigSign$ on inputs a signing key $\skey$ and a message $m \in \MsgSp$ outputs a signature $\sig$. The deterministic verification algorithm $\SigVf$ on inputs a verification key $\vkey$, a message $m \in \MsgSp$, and a signature $\sig$ outputs a bit. We set $\SigVf(\vkey,m,\bot) = 0$. For correctness, we require that there is a negligible $\nu_{\mathsf{corr}}$ such that
$$
 \Pr\big[ \SigVf\big(\vkey, m, \SigSign(\skey, m)\big) \Rightarrow 1 \big]
 \ge 1 - \nu_{\mathsf{corr}}(\secp)
$$
for all $m \in \MsgSp$, where the probability is over $(\vkey,\skey) \getsr \SigKeys$ and the coins for $\SigSign$. The Schnorr schemes of Part~I meet this with $\nu_{\mathsf{corr}} = 0$. The scheme of Part~II uses rejection sampling and returns $\bot$ when every attempt is rejected, which happens with probability at most $2^{-\secp}$, so it meets the relaxed requirement and not the perfect one.

\heading{Keyed hash families.} A \emph{keyed hash family} for a group $\GG$ of prime order $p$ and message space $\MsgSp$ is a pair $\HF = (\HFKg, \HFEv)$ that works as follows. The key-generation algorithm $\HFKg$ on input a group element $X \in \GG$ outputs a hash key $\hk$. The deterministic evaluation algorithm $\HFEv$ on inputs $\hk$ and a pair $(R,m) \in \GG \times \MsgSp$ outputs an element of $\Zp$.

\paragraph*{Discussion.} The hash key is allowed to depend on the group element $X$, which in our schemes is the Schnorr verification key. The hash key is generated honestly at key-generation time and placed in the verification key. The BK-CMA construction ignores $X$, so its hash key is independent of the signing key. Our unforgeability constructions instead embed $X$ in an obfuscated program. Generating the hash key at key-generation time is the same modeling choice as in the full-domain-hash instantiation of Hohenberger, Sahai, and Waters~\cite{EC:HohSahWat14}. It means each user has their own hash function, which is public and part of the verification key.

\heading{Schnorr signatures relative to a hash family.} Let $\GG$ be a cyclic group of prime order $p = |\GG|$, generated by $g$. Let $\HF$ be a keyed hash family for $\GG$ and message space $\MsgSp$. The \emph{Schnorr signature scheme}~\cite{C:FiaSha86,C:Schnorr89} $\SchScheme[\GG,\HF] = (\SchKeys,\SchSign,\SchVf)$ with message space $\MsgSp$ works as follows. Algorithm $\SchKeys$ chooses $x \getsr \Zp$, sets $X \gets g^x$, computes $\hk \getsr \HFKg(X)$, and returns $(\vkey=(X,\hk),\skey=(x,\hk))$. Algorithm $\SchSign$ on input $\skey,m$ chooses $\rho \getsr \Zp$, sets $R \gets g^{\rho}$ and $c \gets \HFEv(\hk, (R, m))$, then returns $\big(R,(\rho+ cx)\bmod p\big)$. Algorithm $\SchVf$ on inputs $(X,\hk),m,(R,s)$ returns $\big(g^s = R \cdot X^c\big)$ where $c \gets \HFEv(\hk, (R, m))$.
Correctness follows by substitution. We take $\MsgSp = \bits^{\msglen}$ for a polynomial $\msglen = \msglen(\secp)$.

\paragraph*{Discussion.} Restricting to fixed-length messages loses no generality. For the key-recovery result, an arbitrary efficient public map from $\bits^*$ to $\bits^{\msglen}$ suffices: collisions do not help an adversary recover the secret exponent. If one wants a single unforgeability scheme for arbitrary-length messages, one may first apply a collision-resistant hash function whose key is placed in the verification key. A forgery on a fresh message whose digest collides with a queried message's digest then gives a collision. The unforgeability results below are stated directly for messages of a fixed polynomial length and do not assume collision resistance.

\heading{Unforgeability.} Let $\SigScheme = (\SigKeys, \SigSign,\SigVf)$ be a signature scheme with message space $\MsgSp$. We define two security games, given in Figure~\ref{fig-eufcma}. For an adversary $\advA$, its EUF-CMA advantage is
$$
\AdvEUFCMA{\SigScheme}{\advA}
=\Pr\big[\gameEUFCMA{\SigScheme}(\advA)\Rightarrow1\big].
$$
For $\advA=(\advA_0,\advA_1)$, its \emph{static-message} unforgeability advantage is
$$
\AdvEUFSTATIC{\SigScheme}{\advA}
=\Pr\big[\gameEUFSTATIC{\SigScheme}(\advA)\Rightarrow1\big].
$$
For a polynomial $Q$, the game $\gameEUFSTATIC{\SigScheme}$ with the added requirement $q_s \le Q(\secp)$ on the declared list is denoted $\mathrm{EUF\text{-}static}[Q]$, and the corresponding advantage is $\AdvEUFSTATICQ{\SigScheme}{\advA}$. We use the bounded notion for the two obfuscation-based constructions whose hash circuit is padded to a size determined by $Q$. Elsewhere we use the ordinary notion, with no scheme-level query parameter.
\end{samepage}

\paragraph*{Discussion.} In EUF-static, the adversary declares its signing messages $m_1,\ldots,m_{q_s}$ and its forgery message $m^*$ before seeing the verification key, and then receives all requested signatures at once. This is weaker than the selective-target notion of Hohenberger, Sahai, and Waters~\cite{EC:HohSahWat14}, where only the forgery message is declared before key generation and signing queries remain adaptive.

\subsection{Discrete-Logarithm and Circular Discrete-Logarithm Problems} \label{sec-dl-cdl}

We recall the \emph{discrete-logarithm} (DL) problem.
Let $\GG$ be a group of prime order $p = |\GG|$, generated by $g$. For an adversary $\advA$, we let its DL-advantage against $\GG,g$ be $\AdvDL{\GG,g}{\advA} = \Pr\big[\gameDL{\GG,g}(\advA) \Rightarrow 1\big]$, where the game is in Figure~\ref{fig-cdl}.

We recall the \emph{circular discrete-logarithm} (CDL) problem, introduced by Cho, Fuchsbauer, O'Neill, and Sefranek~\cite{C:CFOS25}.
Let $\GG$ be as above and let $f \colon \GG \to \Zp$ be an efficient function, called the \emph{conversion function}. For an adversary $\advA$ we let its CDL-advantage against $\GG,g,f$ be $\AdvCDL{\GG,g,f}{\advA} = \Pr\big[\gameCDL{\GG,g,f}(\advA) \Rightarrow 1\big]$, where the game is in Figure~\ref{fig-cdl}.

\paragraph*{Discussion.} The ``circularity'' in CDL is that in the solution equation $R$ occurs both in the base and in the exponent, mirroring the verification equation of Schnorr signatures. CDL is non-interactive and, for a fixed $f$, falsifiable in the sense of Naor~\cite{C:Naor03}. It cannot hold if some nonzero value has a large preimage under $f$; \cite{C:CFOS25} show that in the elliptic-curve generic group model of Groth and Shoup~\cite{EC:GroSho22} this condition on $f$ is also sufficient, and that the ECDSA conversion function $f_{\mathsf{ecdsa}} \colon (x,y) \mapsto x \bmod p$ satisfies it. CDL is random self-reducible~\cite{C:CFOS25}. For our results we require, as in~\cite{C:CFOS25}, that $\mathsf{Size}_f(0)/p$ is negligible and that $f$ is efficient.

\begin{lemma}[DL and zero-free CDL] \label{lem-dl-cdl}
Let $f\colon\GG\to\Zp$ have no zeros. For every DL adversary $\advB$ there is a CDL adversary $\advB'$ of the same running time up to a fixed polynomial overhead such that
$$
\AdvDL{\GG,g}{\advB}=\AdvCDL{\GG,g,f}{\advB'}.
$$
Moreover, there is a PPT CDL adversary with advantage exactly $1/p$.
\end{lemma}

\begin{proof}
On input $h$, adversary $\advB'$ runs $\advB(h)$ to obtain $x'$ and returns
$$
\bigl(1_\GG,x'f(1_\GG)\bmod p\bigr).
$$
If $h=g^x$, this pair satisfies the CDL equation exactly when $x'=x$, because $f(1_\GG)\ne0$ and $p$ is prime. This proves the equality of advantages. For the final claim, choose $z\getsr\Zp$ and return $(1_\GG,z)$. The output wins exactly when $z=xf(1_\GG)\bmod p$, which occurs with probability $1/p$.
\end{proof}

\subsection{Tunable Lossy Functions} \label{sec-lf}

We define a lossy function whose image bound is an input to key generation. We use it in two ways. In the key-recovery result, the reduction enumerates the lossy image and rejection-samples signatures. In the adaptive unforgeability result, the reduction guesses a digest from that image. The image parameter controls these costs together with the indistinguishability of the two modes.

Let $M=2^{\ellin}$, where $\secp\le\ellin=\poly(\secp)$, and let $\Ygrave$ be a range whose elements have polynomial-size descriptions. The lower bound on $\ellin$ is without loss of generality, since an encoding can be padded.

\begin{definition} \label{def-lf}
A \emph{tunable lossy function with enumerable image} is a triple $\TLF=(\TLFKg,\TLFEv,\TLFEnum)$ with the following syntax. Algorithm $\TLFKg$ takes $(\usecp,r,\mathsf{mode})$, where $1\le r\le M$ is the image bound and $\mathsf{mode}\in\{\mathsf{inj},\mathsf{lossy}\}$, and outputs a key $K$ together with enumeration information $\mathsl{td}$, in time polynomial in $\secp$. The deterministic algorithm $\TLFEv$ takes $K$ and $x\in\bits^{\ellin}$ and outputs an element of $\Ygrave$, in time polynomial in $\secp$. Algorithm $\TLFEnum$ takes $\mathsl{td}$, which includes $r$, and outputs a list of at most $r$ elements of $\Ygrave$.

There are functions $\nu_{\mathsf{inj}}$, $\nu_{\mathsf{enum}}$, and $\tau$ such that the following hold for every $r\in[M]$, where all probabilities are over the coins of $\TLFKg$ and $\TLFEnum$, and $\tau(\secp,r)$ bounds the running time of $\TLFEnum$.
\begin{enumerate}
\item \emph{Injectivity.} If $(K,\mathsl{td})\getsr\TLFKg(\usecp,r,\mathsf{inj})$, then $\TLFEv(K,\cdot)$ is injective, except with probability $\nu_{\mathsf{inj}}(\secp,r)$.
\item \emph{Lossiness and enumeration.} If $(K,\mathsl{td})\getsr\TLFKg(\usecp,r,\mathsf{lossy})$ and $S\getsr\TLFEnum(\mathsl{td})$, then
$$
\Image(\TLFEv(K,\cdot))\subseteq S ,
$$
except with probability $\nu_{\mathsf{enum}}(\secp,r)$. Since $|S|\le r$, the lossy image then has at most $r$ elements.
\end{enumerate}
The advantage of $\advA$ in distinguishing the modes at image bound $r$ is
$$
\AdvTLF{\TLF,r}{\advA}
:=
\Bigl|
\Pr\bigl[\advA(K)=1:(K,\mathsl{td})\getsr\TLFKg(\usecp,r,\mathsf{inj})\bigr]
-
\Pr\bigl[\advA(K)=1:(K,\mathsl{td})\getsr\TLFKg(\usecp,r,\mathsf{lossy})\bigr]
\Bigr| .
$$
The distinguisher receives the key alone. It does not receive the enumeration information.
\end{definition}

Definition~\ref{def-lf} does not fix the relation among $r$, $\AdvTLF{\TLF,r}{\advA}$, and $\tau(\secp,r)$; each result states the tradeoff it uses. A fixed-parameter lossy function is obtained by choosing one function $r=r(\secp)$.

\paragraph*{Comparison with prior notions.}
Lossy trapdoor functions~\cite{STOC:PeiWat08} fix the amount of lossiness in the
family and require the injective mode to be invertible given a trapdoor. Three
things differ here. We never invert, so we require no inversion trapdoor, and
$\mathsl{td}$ carries enumeration information only. We require the lossy image to
be listable, which lossy trapdoor functions do not provide and which every use in
this paper needs. And the image bound is an input to key generation rather than a
parameter of the family.

Zhandry's extremely lossy functions~\cite{C:Zhandry16,EPRINT:Zhandry16} also take
the image bound at key generation. Definition~\ref{def-tlf-strong} below is their
security requirement, stated in our syntax: the image bound may be chosen as a
polynomial after the running time of the distinguisher is fixed. We keep that
requirement separate from Definition~\ref{def-lf} because our LWE-based
construction does not meet it. That construction gives a fixed image bound with a
stated tradeoff (Proposition~\ref{prop-tlf-lwe}), and the results that use it
state the tradeoff they need.

\paragraph*{Injective key generation.}
Every construction in this paper that uses a TLF invokes
$\TLFKg(\usecp,r,\mathsf{inj})$. The lossy generator is used only in the
security proofs. Thus ``injective'' and ``lossy'' are the two formal modes;
honest key generation is the larger scheme algorithm that invokes the
injective mode.

We say that the injective mode is \emph{universal} if, for every $r,r'\in[M]$,
the marginal distributions of $K$ in
$$
(K,\mathsl{td})\getsr\TLFKg(\usecp,r,\mathsf{inj})
\qquad\text{and}\qquad
(K,\mathsl{td})\getsr\TLFKg(\usecp,r',\mathsf{inj})
$$
are identical. The condition concerns the public key $K$ rather than the
enumeration information, which the scheme discards. Universality lets a proof
choose $r$ without changing the deployed function family.

\begin{definition} \label{def-tlf-strong}
A TLF is \emph{strongly efficiently enumerable} if its injective mode is
universal and the following holds. For every polynomial time bound $t$ and
inverse-polynomial function $\epsilon$, there is a polynomial $q$ such that,
for every $r\in[q(\secp),M]$, every distinguisher $\advA$ of running time at
most $t(\secp)$ satisfies
$$
\AdvTLF{\TLF,r}{\advA}\le\epsilon(\secp).
$$
For every polynomially bounded function $r=r(\secp)$,
$\nu_{\mathsf{inj}}(\secp,r)$ and
$\nu_{\mathsf{enum}}(\secp,r)$ are negligible and
$\tau(\secp,r)$ is polynomial in $\secp$ and $r$.
\end{definition}

The order of quantifiers in Definition~\ref{def-tlf-strong} is useful when a
reduction must remain polynomial time. After fixing a particular PPT
adversary, the proof may choose a sufficiently large polynomial $r$. Since
the injective distribution is universal, neither the deployed family nor its
parameters depend on that adversary. A fixed superpolynomial value of $r$
gives a different and often simpler tradeoff: the TLF need only hide its modes
from PPT distinguishers, while the reduction that enumerates the image must
be allowed time polynomial in $r$.

\paragraph*{DDH-based TLFs.}
We record the two forms of the construction that Zhandry originally presented as
an extremely lossy function~\cite{C:Zhandry16,EPRINT:Zhandry16}. The one-level
form is in Figure~\ref{fig-tlf-ddh}. It works over an auxiliary group of prime
order chosen to be smaller than the requested image bound. Set
$$
\mu=\max\{j\ge1:2^{j+1}<r\},
$$
let the auxiliary group have prime order $p_\mu\in[2^\mu,2^{\mu+1})$, so that
$p_\mu<r$ and $\mu=\Theta(\log r)$, and put $m=\lceil\log_{p_\mu}M\rceil$ and
$n=2m$. The domain is encoded injectively in $\Z_{p_\mu}^{m}$ by base-$p_\mu$
digits. The key is a matrix of group elements, and the two modes differ only in
the distribution of its exponent matrix: uniform in injective mode, and rank one
in lossy mode, where the generator retains a vector spanning the column space.

\begin{proposition}[DDH-based TLFs] \label{prop-tlf-ddh}
For each polynomial-time computable integer function
$8\le r=r(\secp)\le M$, the one-level construction gives a fixed-parameter
TLF for which
$$
\nu_{\mathsf{inj}}(\secp,r)\le 1/M,\qquad
\nu_{\mathsf{enum}}(\secp,r)=0,\qquad
\tau(\secp,r)\le r\poly(\secp).
$$
Let $p_\mu$ be the order of the auxiliary group with security parameter
$$
\mu=\Theta(\log r),
$$
and put $m=\lceil\log_{p_\mu}M\rceil$. For every distinguisher $\advD$ there
is a DDH adversary $\advB$, running in time
$t_{\advD}+\poly(\secp)$, such that
$$
\AdvTLF{\TLF,r}{\advD}
\le m\AdvDDH{\GG_\mu}{\advB},
\qquad
m\le\left\lceil\frac{\ellin}{\mu}\right\rceil.
$$
The injective-key distribution in this fixed-parameter construction may
depend on $r$.

Under exponential DDH, Zhandry's cascade gives a strongly efficiently
enumerable TLF. Its injective-key distribution is universal, its image
enumeration takes $r\poly(\secp)$ time for every $2\le r\le M$, and it has
negligible injectivity failure and zero enumeration failure.

More generally, for any fixed $k\ge1$, Zhandry's rank-$k$ construction and
the same cascade give these conclusions under the exponential decisional
$k$-linear assumption; the case $k=1$ is exponential
DDH~\cite[Theorem~3.14 and Corollary~3.15]{EPRINT:Zhandry16}.
\end{proposition}

\begin{proof}
Consider the one-level construction of Figure~\ref{fig-tlf-ddh}. A uniform
matrix in $\Z_{p_\mu}^{n\times m}$ has full column rank except with probability
at most $1/M$, and evaluation is injective whenever the exponent matrix has full
column rank, so $\nu_{\mathsf{inj}}(\secp,r)\le1/M$. In lossy mode the exponent
matrix is $\mat{a}\mat{b}^{\mathsf T}$, so every value of $\mat{A}\bar x$ is a
multiple of $\mat{a}$ and the image is contained in
$\{g^{z\mat{a}}:z\in\Z_{p_\mu}\}$. The enumerator lists exactly that set, which
has $p_\mu<r$ elements, so $\nu_{\mathsf{enum}}(\secp,r)=0$ and enumeration takes
$r\poly(\secp)$ time. The two modes differ only in whether the exponent matrix is
uniform or rank one, and distinguishing those distributions reduces to DDH in the
auxiliary group, with the stated factor $m$, by the matrix-rank hybrid of
Zhandry~\cite[Theorem~3.14]{EPRINT:Zhandry16}.

The universal construction is Zhandry's
cascade~\cite[Theorem~3.9]{EPRINT:Zhandry16}. Its enumerable-image guarantee
uses Lemma~3.6 and Corollary~3.15 of the same work.
It places one such component at each of a sequence of auxiliary security
levels and connects them with pairwise-independent maps. An injective key
uses the injective distribution at every level and is therefore independent
of $r$. A lossy key changes only the component corresponding to the requested
image bound. For an arbitrary $r$, let $s$ be the unique power of two in
$(r/2,r]$ and switch the component indexed by $s$. Retaining a basis for that
component's exponent-space column image lets the enumerator list fewer than
$s\le r$ component outputs and apply the fixed suffix of the cascade to each
one. This gives an exact cover of the final image in $r\poly(\secp)$ time, so
$\nu_{\mathsf{enum}}(\secp,r)=0$. Exponential DDH hides the changed component
even when the proof chooses a polynomial $r$ after fixing the distinguisher.
Taking the injective generator at bound $M$, the lossy generator at bound $r$,
and this enumerator gives the TLF syntax of Definition~\ref{def-lf}.
\end{proof}

Following Zhandry~\cite[Definition~3.11]{EPRINT:Zhandry16}, exponential DDH
means that there is a polynomial $q$ such that, for every time bound $t$ and
target advantage $\epsilon$, DDH in the group generated at security parameter
$\mu=\log q(t,1/\epsilon)$ has advantage at most $\epsilon$ against every
$t$-time adversary. This is stronger than ordinary polynomial-time DDH.

The one-level construction already covers every PPT distinguisher when a
fixed superpolynomial $r$ is paired with the corresponding DDH hardness. If
$r=\secp^{\log\secp}$, then $\mu=\Theta((\log\secp)^2)$ and a
polynomial-time distinguisher in $\secp$ becomes a
$2^{O(\sqrt{\mu})}$-time DDH distinguisher. DDH subexponential security at
any exponent strictly greater than $1/2$ covers this running time and makes
its advantage negligible at the original security parameter. If
$r=2^{\secp^\theta}$ for a constant $0<\theta<1$, then
$\mu=\Theta(\secp^\theta)$, ordinary DDH security at parameter $\mu$ suffices,
and enumeration takes $2^{O(\secp^\theta)}$ time. In both cases the image bound
is fixed independently of the adversary. The cascade supplies the stronger
endpoint in which $r$ may instead be a polynomial selected after the
adversary is fixed.

\paragraph*{An LWE-based TLF.}
Lossy functions originate with Peikert and
Waters~\cite{STOC:PeiWat08,JACM:PeiWat11}. The rounded-matrix core used here
follows Alwen, Krenn, Pietrzak, and Wichs~\cite{C:AKPW13}, while the boundary
test and multi-component boosting follow Waters and Zhandry's
length-parameterized lossy function~\cite{C:WatZha24}. Those works do not
state the resulting function with a tunable image enumerator. We make the
latent dimension tunable and retain part of the lossy-generation randomness,
which yields a polynomial-overhead cover of the image. Both of our
applications need such a covering set rather than merely an image-size bound.

Write $\ell=\ellin$ and $N=\ell+\secp$. We use a lattice trapdoor generator
that, on input $(q_{\mathsf L},\ell,m)$ for
$m=\Omega(\ell\log q_{\mathsf L})$, returns
$$
(A,S)\in\Z_{q_{\mathsf L}}^{m\times\ell}\times\Z^{m\times m}
$$
such that $A$ has full column rank over $\Z_{q_{\mathsf L}}$, $S$ has full
rank over $\mathbb{Q}$, and $SA=0\bmod q_{\mathsf L}$. Let
$L_{\mathsf{trap}}$ bound the absolute values of the entries of $S$, and let
$\delta_{\mathsf{trap}}$ be the
statistical distance between $A$ and a uniform matrix in
$\Z_{q_{\mathsf L}}^{m\times\ell}$. Such a generator is given by the trapdoor
construction
used by Waters and Zhandry~\cite{C:WatZha24}.

Fix a prime modulus $q_{\mathsf L}$, a number of rows $m$, and a rounding
parameter $t\le q_{\mathsf L}$, all polynomially bounded in $\secp$ and fixed
independently of the requested image bound. Partition $\Z_{q_{\mathsf L}}$
into $t$ intervals of nearly equal size, let
$\mathcal{C}_t\subseteq\Z_{q_{\mathsf L}}$ be their centers, and let
$$
\mathsf{Round}_t\colon\Z_{q_{\mathsf L}}^m\longrightarrow\mathcal{C}_t^m
$$
map each coordinate to the center of its interval. All distances below are
cyclic distances in $\Z_{q_{\mathsf L}}$, represented by the least absolute
centered residue. Let $\chi_\sigma$ be a discrete Gaussian of width $\sigma$, let
$\chi_{\sigma,B}$ be this distribution conditioned to $[-B,B]$, and write
$\delta_{\mathsf{tail}}$ for their statistical distance. We choose the
remaining parameters as in the LWE construction of Waters and Zhandry, with
$\sigma=\omega(\log\secp)$, $B/\sigma=\omega(\log\secp)$, and
$$
q_{\mathsf L}\ge3mt(2\ell B+3)
\qquad\text{and}\qquad
L_{\mathsf{trap}}m(q_{\mathsf L}/t+1)<q_{\mathsf L}/2,
$$
and with
$$
N\delta_{\mathsf{trap}}+Nm\ell\delta_{\mathsf{tail}}=\negl(\secp).
$$
The second inequality makes the rounded injective-mode function injective.
The first bounds the chance of landing near a rounding boundary; together
with $q_{\mathsf L}^\kappa\ge4$, it gives the one-half acceptance probability
used below.

For $A\in\Z_{q_{\mathsf L}}^{m\times\ell}$ and $x\in\bits^\ell$, define
$\mathsf{Far}(A,x)=1$ if $x=0^\ell$, or if every coordinate of $Ax$ has
distance greater than $\ell B+1$ from every rounding boundary. Otherwise set
$\mathsf{Far}(A,x)=0$. For an image bound $r\ge Nq_{\mathsf L}$, put
$$
\kappa=\kappa(r):=\max\{k\ge1:Nq_{\mathsf L}^k\le r\}.
$$
A public key has the form $K=(A_1,\ldots,A_N)$. On input $x$, evaluation
finds the least $i$ such that $\mathsf{Far}(A_i,x)=1$ and returns
$$
\TLFEv(K,x)=\bigl(i,\mathsf{Round}_t(A_ix)\bigr).
$$
If no such index exists, it returns $(0,x)$.
The range is the disjoint union
$$
\Ygrave_{\mathsf L}
:=
(\{0\}\times\bits^\ell)
\mathbin{\dot\cup}
([N]\times\mathcal{C}_t^m),
$$
so the fallback output and the rounded outputs are unambiguously typed.

In injective mode, key generation independently samples
$$
(A_i,S_i)\getsr\mathsf{TrapGen}(q_{\mathsf L},\ell,m)
\qquad\text{for }i\in[N],
$$
publishes $K=(A_1,\ldots,A_N)$, and discards the matrices $S_i$. In lossy
mode, it samples
$$
U_i\getsr\Z_{q_{\mathsf L}}^{m\times\kappa},\qquad
V_i\getsr\Z_{q_{\mathsf L}}^{\kappa\times\ell},\qquad
E_i\getsr\chi_{\sigma,B}^{m\times\ell},
$$
sets $A_i=U_iV_i+E_i\bmod q_{\mathsf L}$, and retains $r,\kappa$, and the
matrices $U_i$ as enumeration information. The enumerator removes duplicates
from
$$
\left\{
\bigl(i,\mathsf{Round}_t(U_i u)\bigr):
i\in[N],\ u\in\Z_{q_{\mathsf L}}^\kappa
\right\}.
$$
The three algorithms are collected in Figure~\ref{fig-tlf-lwe}.

For values $r<Nq_{\mathsf L}$, use the same injective generator, define the
lossy generator and enumerator arbitrarily, and set
$\nu_{\mathsf{enum}}(\secp,r)=1$. Thus the injective distribution remains
universal, although none of our applications use this range.

\begin{proposition} \label{prop-tlf-lwe}
The construction above is a TLF with a universal injective mode. Whenever
$r\ge Nq_{\mathsf L}$ and $q_{\mathsf L}^{\kappa(r)}\ge4$, it satisfies
$$
\nu_{\mathsf{inj}}(\secp,r)=0,\qquad
\nu_{\mathsf{enum}}(\secp,r)\le2^{-\secp},\qquad
\tau(\secp,r)\le r\poly(\secp).
$$
Let $\epsilon_{\mathsf{lwe}}$ bound decisional matrix-LWE advantage at secret
dimension $\kappa(r)$, $m$ rows, $\ell$ columns, modulus $q_{\mathsf L}$, and
error width $\sigma$. Then every mode distinguisher of comparable running time has
advantage at most
$$
N\delta_{\mathsf{trap}}
+N\epsilon_{\mathsf{lwe}}
+Nm\ell\delta_{\mathsf{tail}}.
$$
\end{proposition}

\begin{proof}
For an injective-mode matrix $A_i$, let
$y=\mathsf{Round}_t(A_ix)$ and write $y=A_ix+e$ over centered
representatives, where $\|e\|_\infty\le q_{\mathsf L}/t+1$. Since
$S_iA_i=0\bmod q_{\mathsf L}$, the centered representative of
$S_iy\bmod q_{\mathsf L}$ equals
$S_ie$: the displayed bound gives
$$
\|S_ie\|_\infty
\le L_{\mathsf{trap}}m(q_{\mathsf L}/t+1)<q_{\mathsf L}/2.
$$
As $S_i$ has full rank over $\mathbb{Q}$, the trapdoor recovers $e$, and
therefore $A_ix=y-e$, from the rounded value
$$
\mathsf{Round}_t(A_ix).
$$
Since $A_i$ has full column rank, the rounded map is injective. The output
index separates inputs that select different matrices, while $(0,x)$ is
itself injective, proving perfect injectivity of the complete function.

Now fix a lossy key. Whenever $\mathsf{Far}(A_i,x)=1$, we have
$\|E_ix\|_\infty\le\ell B$, so $A_ix$ and $U_iV_ix$ lie in the same rounding
intervals. It follows that
$$
\mathsf{Round}_t(A_ix)=\mathsf{Round}_t(U_iV_ix).
$$
Taking $u=V_ix$ shows that every output selecting index $i$ appears in the
enumerated set.

For each fixed nonzero $x$, the vector $V_ix$ is uniform in
$\Z_{q_{\mathsf L}}^\kappa$ and is nonzero except with probability
$q_{\mathsf L}^{-\kappa}$. Conditioned on this
event, $U_iV_ix+E_ix$ is uniform in every coordinate. The modulus bound and
a union bound over the $m$ coordinates show that the boundary test accepts
with probability at least $2/3$. Since $q_{\mathsf L}^\kappa\ge4$, its
unconditional acceptance probability is at least $1/2$; the zero input is accepted by
definition. The $N$ components are independent. For any fixed input the
probability that none accepts is therefore at most $2^{-N}$, and a union
bound over the $2^\ell$ inputs bounds the probability of any fallback output
by $2^\ell2^{-N}=2^{-\secp}$. Outside this event the enumerated set covers
the complete image. Its size is at most $Nq_{\mathsf L}^\kappa\le r$, and it
can be generated in $r\poly(\secp)$ time.

For mode indistinguishability, replace the trapdoor-generated matrices by
uniform matrices, and then replace them by $U_iV_i+E_i$ one at a time. The
latter are standard matrix-LWE hybrids; reducing each to ordinary LWE by a
column hybrid loses a further factor $\ell$. Finally, replace the unbounded
Gaussian by its bounded version. The
trapdoor-generator and Gaussian-tail terms are negligible for the stated
parameters, which proves the claim. Since the injective public key always
consists of $N$ independently trapdoor-generated matrices and its
distribution contains neither $r$ nor $\kappa(r)$, the injective mode is
universal.
\end{proof}

The LWE construction is most simply used with a fixed superpolynomial image
bound. For example, if all outer dimensions are polynomial in $\secp$,
$q_{\mathsf L}=\secp^{\Theta(1)}$, and $r=2^{\secp^\theta}$ for a constant
$0<\theta<1$, then
$$
\kappa(r)=\Theta(\secp^\theta/\log\secp)
\qquad\text{and}\qquad
\tau(\secp,r)=2^{O(\secp^\theta)}.
$$
Ordinary LWE at dimension $\kappa(r)$ and the displayed polynomially related
parameters then hides the modes from every PPT distinguisher in $\secp$.
For smaller fixed values of $r$, including quasi-polynomial $r$, the exact
assumption is the parameterized matrix-LWE statement in
Proposition~\ref{prop-tlf-lwe}. Unlike the DDH cascade, this construction is
not claimed to meet Definition~\ref{def-tlf-strong} at polynomial image
bounds.

\subsection{Pseudorandom Functions and Puncturable Pseudorandom Functions} \label{sec-pprf}

For an ordinary keyed function family $\PRF=(\PRFKg,\PRFEv)$ with domain $\mathcal X$ and finite range $\mathcal Z$, define
$$
\begin{aligned}
\AdvPRF{\PRF}{\advD}
&:=
\bigl|
\Pr\bigl[\advD^{\PRFEv(k,\cdot)}(\usecp)\Rightarrow1:
            k\getsr\PRFKg(\usecp)\bigr]\\
&\quad-
\Pr\bigl[\advD^{\varphi(\cdot)}(\usecp)\Rightarrow1:
            \varphi\getsr\mathcal Z^{\mathcal X}\bigr]
\bigr|,
\end{aligned}
$$
where $\varphi$ is a uniformly sampled function, implemented by lazy sampling. The family is a pseudorandom function if this advantage is negligible for every PPT distinguisher.

\begin{definition} \label{def-pprf}
A \emph{puncturable pseudorandom function} with domain $\bits^{\ellin'}$ and range $\mathcal{Z}$ is a tuple $\PRF = (\PRFKg, \PRFEv, \PRFPunc)$ that works as follows. The key-generation algorithm $\PRFKg$ on input $\usecp$ outputs a key $k$. The deterministic evaluation algorithm $\PRFEv$ on inputs $k$ and $x \in \bits^{\ellin'}$ outputs an element of $\mathcal{Z}$. The puncturing algorithm $\PRFPunc$ on inputs $k$ and a set $T \subseteq \bits^{\ellin'}$ of polynomial size outputs a punctured key $k\{T\}$. We require:
\begin{enumerate}
\item \emph{Functionality preservation:} for all $k \in \OutSet{\PRFKg(\usecp)}$, all polynomial-size $T$, all $k\{T\} \in \OutSet{\PRFPunc(k,T)}$, and all $x \notin T$, it holds that $\PRFEv(k\{T\},x) = \PRFEv(k,x)$.
\item \emph{Pseudorandomness at punctured points:} let $\mathcal{S}$ be any time-bounded probabilistic sampler that on input $\usecp$ outputs a polynomial-size set $T$ and state $\state$, independently of the PRF key. For every time-bounded probabilistic distinguisher $\advD$, define
$$
\begin{aligned}
&\AdvPPRF{\PRF}{(\mathcal S,\advD)}\\
&\quad:=
\bigl|
\Pr\!\left[\advD(\state,T,k\{T\},(\PRFEv(k,x))_{x\in T})\Rightarrow1\right]
\\[-0.25ex]
&\qquad-
\Pr\!\left[\advD(\state,T,k\{T\},(u_x)_{x\in T})\Rightarrow1\right]
\bigr|,
\end{aligned}
$$
where $(T,\state)\getsr\mathcal{S}(\usecp)$, $k\getsr\PRFKg(\usecp)$, $k\{T\}\getsr\PRFPunc(k,T)$, and $u_x\getsr\mathcal{Z}$ independently for each $x\in T$. The displayed formula defines the quantitative advantage for any such pair. We require this advantage to be negligible for every PPT pair $(\mathcal S,\advD)$.
\end{enumerate}
\end{definition}

When a theorem writes $\AdvPPRF{\PRF}{\advD'}$, the symbol $\advD'$ denotes the sampler--distinguisher pair in this definition. Its running time is the combined worst-case running time of the sampler and the distinguisher.

Puncturable PRFs follow from one-way functions via the GGM construction~\cite{AC:BonWat13,EC:BoyGilIsh15,CCS:KPTZ13}.

\paragraph*{Exact ranges.} Several steps in our proofs replace a PRF output by a value that is \emph{exactly} uniform on $\Zp$, on $\chal_q$, or on an integer box. We therefore state the results for PRFs having exactly these ranges. A bit-output PRF can instead be followed by bounded rejection sampling: draw $\secp$ sufficiently long blocks, return the first unbiased reduction into the desired finite range, and use a fixed default if all blocks fail. Conditioned on avoiding the default, the output is exactly uniform. The default has probability at most $2^{-\secp}$, so this implementation adds at most $q_s2^{-\secp}$ to our bounds, which we suppress. Thus an equality called exact below is exact for the stated exact-range primitive, and is statistical up to this explicit negligible term for the bounded bit-output implementation.

\subsection{Indistinguishability Obfuscation} \label{sec-io}

\begin{definition} \label{def-io}
A PPT algorithm $\iO$ is an \emph{indistinguishability obfuscator} for a circuit class $\{\mathcal{C}_\secp\}$ if the following hold.
\begin{enumerate}
\item \emph{Correctness:} for all $\secp$, all $\CircC \in \mathcal{C}_\secp$, all $\tilde{\CircC} \in \OutSet{\iO(\usecp, \CircC)}$, and all inputs $w$, it holds that $\tilde{\CircC}(w) = \CircC(w)$.
\item \emph{Indistinguishability:} let $\mathcal{S}$ be any time-bounded probabilistic sampler that on input $\usecp$ outputs circuits $\CircC_0,\CircC_1\in\mathcal{C}_\secp$ and state $\state$, where the circuits have the same size and compute the same function. For every time-bounded probabilistic distinguisher $\advD$, define
$$
\begin{aligned}
&\AdvIO{\iO}{(\mathcal S,\advD)}\\
&\quad:=
\bigl|
\Pr[\advD(\state,\iO(\usecp,\CircC_0))\Rightarrow1]
\\[-0.25ex]
&\qquad-
\Pr[\advD(\state,\iO(\usecp,\CircC_1))\Rightarrow1]
\bigr|,
\end{aligned}
$$
where $(\CircC_0,\CircC_1,\state)\getsr\mathcal{S}(\usecp)$. The displayed formula defines the quantitative advantage for any such pair. We require this advantage to be negligible for every PPT pair $(\mathcal S,\advD)$.
\end{enumerate}
\end{definition}

When a theorem writes $\AdvIO{\iO}{\advD'}$, the symbol $\advD'$ denotes the sampler--distinguisher pair in this definition, with their combined worst-case running time.

Existing constructions derive indistinguishability obfuscation from explicit falsifiable assumptions~\cite{STOC:JaiLinSah21,EC:JaiLinSah22}. When we obfuscate a circuit, we pad it to the maximum size of the circuits appearing in the security proof; we do not mention this padding again.

\heading{Subexponential security.} We say a puncturable PRF, an indistinguishability obfuscator, or a problem such as DL or CDL is \emph{subexponentially secure with parameter $\delta$}, for a constant $0 < \delta < 1$, if every possibly non-uniform adversary running in time at most $2^{\secp^{\delta}}$ has advantage at most $2^{-\secp^{\delta}}$ in the corresponding game, for all sufficiently large $\secp$. The adaptive Deterministic Schnorr theorem is stated with an explicit advantage bound $\eps$; subexponential security is one way to satisfy its fixed-image specialization, and the displayed quasi-polynomial profile suffices when the lossy image bound of the TLF digest layer is quasi-polynomial (Corollary~\ref{cor-der-adaptive}). A strongly efficiently enumerable TLF instead gives ordinary PPT security for the remaining assumptions (Corollary~\ref{cor-der-adaptive-strong}). The bounded static-message Schnorr result uses ordinary PPT security for CDL, iO, and puncturable PRFs. The BK-CMA theorem states its TLF and DL tradeoff explicitly.
