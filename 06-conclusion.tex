\section{Open Problems} \label{sec-conclusion}

\heading{Randomized Schnorr.} Section~\ref{sec-derand} proves adaptive security, with no query bound in the scheme, for Deterministic Schnorr, whose signer derives its nonce from the key and message as in EdDSA. It does not cover ordinary randomized Schnorr: the trigger branch produces one signature per digest, while the ordinary randomized signer produces fresh signatures on repeated messages. Adaptive security for randomized Schnorr with the usual two-element signature and no query bound remains open.

\heading{Removing the digest guess.} The adaptive deterministic proof guesses one digest in each signing hybrid and also guesses the forgery digest, losing a factor $r$ each time. The strong-TLF endpoint keeps $r$ polynomial and therefore obtains security from ordinary PPT assumptions, while a fixed quasi-polynomial $r$ gives the explicit quantitative tradeoff of Corollary~\ref{cor-der-adaptive}. A proof that punctures at adaptively selected inputs without guessing would improve this loss and could remove the TLF digest layer from the construction. Prefix-guessing techniques for adaptively secure signatures~\cite{CCS:RamWat14} and adaptive security analyses for GGM-based puncturable PRFs~\cite{AC:FKPR14,C:JKKKPW17} are natural starting points.

\heading{One hash function for all users.} The BK-CMA hash-key generator ignores the Schnorr public key, although our theorem is stated only in the single-user setting and proves only key recovery. In our unforgeability constructions the hash key depends on the user's verification key, so each user has a different hash function. It is open to prove unforgeability using one hash function shared by all users.

\heading{Lyubashevsky-style lattice schemes.} Part~II proves bounded EUF-static security for randomized signing and EUF-static security without a query bound for deterministic signing. The adaptive deterministic port is outlined at the end of Section~\ref{sec-dil-static}. It remains open to remove the flooding condition, give a concrete conversion function and evidence for cSIS/cMSIS over $B_\tau$, carry the construction to modules, and handle compression and hints. These gaps mean that these results do not yet cover ML-DSA itself.

\heading{Extensions.} It would also be interesting to extend the proofs to key-prefixed Schnorr, multi-user security, and threshold signing. Each setting requires a separate treatment of the signing simulation.
